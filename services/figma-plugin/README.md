# AI Engineering Delivery Agent Figma Plugin

This plugin creates a live editable Figma design from a workflow request generated by the AI engineering delivery agent.

## Local demo flow

1. Run the agent with `npm start`.
2. Trigger the Slack workflow or set `RUN_PIPELINE_ON_START=true` for a local simulation.
3. In Figma desktop, import this folder as a development plugin.
4. Run the plugin and enter your agent base URL.
5. Enter a request id like `req_004`, or use `latest`.

The plugin fetches `/api/figma/session/:requestId` from the agent and creates frames, text, cards, and CTA nodes in the current Figma file.
